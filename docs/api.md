# API reference

Base path `/api`. Interactive documentation is generated by FastAPI at **`/docs`** (Swagger UI)
and `/redoc` when the API runs locally (`uvicorn finops.api.main:app`).

- **Auth:** every route except `GET /api/health` and `GET /api/config` needs
  `Authorization: Bearer <Cognito access token>`. In AWS, API Gateway's JWT authorizer checks it
  and the app verifies it again. Demo mode needs no token.
- **Money:** all amounts are **USD** numbers (`*_usd`). The frontend converts to INR using
  `usd_inr_rate` from `/api/config`.
- **Dates:** `YYYY-MM-DD`. Timestamps are ISO-8601 UTC.
- **Errors:** `{"detail": "..."}` with 401, 403, 404, 409, 422 or 429. A 429 also carries a
  `Retry-After` header in seconds.
- **Cost Explorer:** no endpoint calls Cost Explorer except `POST /accounts/{id}/refresh`, which is
  rate-limited. A test (`test_page_load_endpoints_never_call_cost_explorer`) enforces this.
- **Finding IDs** contain `#` (`ec2-idle#i-0abc`), so URL-encode them (`%23`).

## Platform

| Method | Path | Description |
|---|---|---|
| GET | `/api/health` | Liveness: version, demo mode, region. Public. |
| GET | `/api/config` | Frontend bootstrap: demo mode, INR rate, refresh cooldown, remediation flag, Cognito settings. Public, no secrets. |
| GET | `/api/me` | The signed-in user (username, email, groups). |
| GET | `/api/rules` | Metadata of the 8 waste rules with default thresholds. |

## Accounts and onboarding

| Method | Path | Description |
|---|---|---|
| GET | `/api/onboarding` | Step 1 of connecting: platform account ID, a fresh ExternalId, both CloudFormation templates, a CLI command and an optional quick-create link. |
| GET | `/api/accounts` | Connected accounts. |
| POST | `/api/accounts` | Body `{name, role_arn, external_id, remediation_role_arn?}`. The role name must start with `FinOps`. Returns 409 if the AWS account is already connected. Status starts as `pending`. |
| GET / PATCH / DELETE | `/api/accounts/{id}` | Read, rename or set the remediation role ARN, or delete (removes all stored data for the account). |
| POST | `/api/accounts/{id}/test` | AssumeRole with the ExternalId, check the caller identity, list enabled regions. **Free.** |
| POST | `/api/accounts/{id}/refresh` | Manual collection. **202** with a run. **429** + `Retry-After` within the cooldown (default 60 min). 409 if the connection hasn't been tested. In AWS this starts the collector Lambda asynchronously. |
| GET | `/api/accounts/{id}/runs?limit=` | Collection history, including the number of Cost Explorer calls per run. |

## Costs (stored data only)

| Method | Path | Description |
|---|---|---|
| GET | `/costs/summary` | KPIs: month-to-date, last month, same period last month, MoM %, forecast (Cost Explorer or linear), budget %, potential savings, anomalies in the last 30 days. |
| GET | `/costs/daily?start&end&top=6` | Zero-filled daily series: the top N services plus "Other", and a total. Defaults to the last 90 days. |
| GET | `/costs/breakdown?dimension=service\|region\|tag&tag_key&start&end&limit` | Totals with share %. `tag` requires `tag_key`; untagged spend shows as `(untagged)`. |
| GET | `/costs/forecast` | Linear regression (slope, R², days used, anomaly days excluded) vs Cost Explorer's forecast and interval, with actual and predicted days for the chart. |
| GET | `/costs/anomalies?days=90` | Days above mean + 3σ of the trailing 30 days, overall and per service. |

All are under `/api/accounts/{id}`. Ranges are limited to 400 days.

## Resources

| Method | Path | Description |
|---|---|---|
| GET | `/resources?type&region&state&q&missing_tag&sort&order` | Inventory with estimated monthly cost. `q` searches ID, name and `key=value` tags. `sort` is one of `name`, `type`, `region`, `state`, `cost`, `created_at`. The response includes counts by type and the available regions and states. |
| GET | `/resources/export.csv?…same filters` | CSV download. |

## Findings, rules, remediation

| Method | Path | Description |
|---|---|---|
| GET | `/findings?status=open&severity&rule_id` | Findings sorted by severity then savings, with totals by rule and by severity. |
| PATCH | `/findings/{finding_id}` | Body `{status: "open" \| "dismissed"}`. A dismissal survives future rule runs. |
| GET | `/rules` | Rules with the account's **effective** thresholds. |
| POST | `/findings/recompute` | Re-run the rules on the stored inventory. Free. |
| GET | `/remediation/{finding_id}` | Preview: action, AWS API call, savings, warnings, and whether it's enabled (with the reason if not). |
| POST | `/remediation/{finding_id}` | Body `{confirm: true, confirm_resource_id}`. Executes the action. 403 unless remediation is enabled and a remediation role is configured. 400 if the typed ID doesn't match. |

## Budgets, alerts, settings, tags

| Method | Path | Description |
|---|---|---|
| GET / PUT | `/budget` | Body `{monthly_limit_usd, thresholds: [80, 100]}`. GET also returns the actual and forecast percentages and the thresholds crossed. |
| GET | `/alerts?limit=100` | Alert history, newest first, with the channels each alert was delivered to. |
| POST | `/alerts/test` | Send a test message via each enabled channel. Not stored. |
| GET / PUT | `/settings` | Required tags, rule thresholds (unknown keys are rejected with 422), email list and toggles, Slack toggle, and `slack_webhook_url`, which is **write-only**: it's stored in SSM and reads only return `slack_configured`. Changing thresholds or tags re-runs the rules. |
| GET | `/tags/compliance` | Compliance %, missing count per tag, non-compliant resources by cost. |
| GET | `/tags/costs?tag_key&start&end` | Cost per tag value. Defaults to the last 30 days. |
